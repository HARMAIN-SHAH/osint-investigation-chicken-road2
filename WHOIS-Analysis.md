## .app TLD — Special Properties

The `.app` TLD has unique security properties enforced by Google Registry:

- **HTTPS is mandatory** — HTTP is not supported on any `.app` domain
- **HSTS preloading** — the entire `.app` TLD is on the HSTS preload list
- **No HTTP redirect tricks** — browsers enforce HTTPS before any redirect occurs

This means chicken-road2.app will always serve over HTTPS regardless of configuration.
